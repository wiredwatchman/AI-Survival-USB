# Advanced: offline reference material on the same drive

This optional build adds offline reference files next to the AI model. It needs a larger drive, and the sizes below are approximate. Check the current sizes before you download.

## Parts

| Item | Approx. size | Purpose |
|------|--------------|---------|
| Ollama and model | about 6 GB | The AI assistant |
| Kiwix and an offline Wikipedia file | tens of gigabytes; check kiwix.org | Offline encyclopedia |
| Reference PDFs you choose | a few GB | Manuals and guides |
| Optional: AnythingLLM | under 1 GB | A chat window that can search your own PDFs |

Use a drive of at least 128 GB if you add an offline encyclopedia.

## Searching your own PDFs (optional)

1. Install AnythingLLM Desktop on the PC.
2. Point its LLM setting at the local Ollama server at `http://localhost:11434`.
3. Upload your PDFs into a workspace.
4. Ask questions. Answers will draw on your files.

Check every answer against the original document, especially for medical and repair steps.

## Tips

- Only add reference material you have the right to copy.
- Keep a printed copy of key medical and water guides.
